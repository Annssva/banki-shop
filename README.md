# Banki.shop

Тестовое задание по верстке страницы интернет-магазина.

## Стек

* Vue 2 (Options API)
* JavaScript
* Webpack
* SCSS

## Установка

Установить зависимости:

```bash
npm install
```

## Запуск проекта

Запуск режима разработки:

```bash
npm run serve
```

## Сборка проекта

Production-сборка:

```bash
npm run build
```
