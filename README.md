# Banki.shop

Тестовое задание по разработке страницы интернет-магазина картин.

## Описание

Одностраничное приложение интернет-магазина с каталогом картин эпохи Возрождения.

Реализовано:

* отображение списка товаров;
* поиск по названию картины и автору;
* просмотр подробной информации о товаре в модальном окне;
* переключение изображений в карточке товара;
* анимации открытия модального окна и смены изображений;
* процесс покупки с изменением состояния кнопки;
* сохранение добавленных товаров в корзине через `localStorage`;
* адаптивная верстка для разных размеров экрана.

## Стек

* Vue 2 (Options API)
* JavaScript
* Webpack
* SCSS

## Установка

Установить зависимости:

```bash
npm install
```

## Запуск проекта

Запуск режима разработки:

```bash
npm run serve
```

## Сборка проекта

Production-сборка:

```bash
npm run build
```

## Структура проекта

```
src/

├── components/      # Vue-компоненты
```
